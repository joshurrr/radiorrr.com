# Radio RRR built-in soundtracks

Four original instrumental arrangements composed procedurally for this tool:

- Drum and bass — 174 BPM
- Electro — 128 BPM
- Techno — 132 BPM
- Chill — 90 BPM

All sounds are synthesised from oscillators and deterministic noise. No external
recordings, samples or existing songs are included. The full tracks repeat their
arrangement for ten minutes, covering the tool's maximum video duration. Each
has a separate 16-second preview.

Rebuild using NumPy and FFmpeg:

```sh
python scripts/generate-stuck-frame-music.py --ffmpeg /path/to/ffmpeg
```
